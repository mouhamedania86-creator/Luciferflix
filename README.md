# MovieFlix

مشغل IPTV (Xtream Codes) بواجهة على طراز نتفلكس — **أندرويد، أندرويد TV، ويندوز، وiPhone**.

مبني بـ Flutter + `media_kit` (libmpv) كواجهة، وكل المحتوى يجي من سيرفر Xtream واحد.

---

## 📥 كيفاش تحمّل التطبيق

ارفع المشروع على GitHub، ومن تبويب **Actions** حمّل الـ artifacts:

| Artifact | شنو فيه | كيفاش تستعمله |
|---|---|---|
| `MovieFlix-APKs` | ملفات APK للتليفون والتلفاز | خود `app-arm64-v8a-release.apk` (الأكثر توافق) |
| `MovieFlix-Windows` | مجلد `Release` فيه `movieflix.exe` | فك الضغط وشغّل `movieflix.exe` |
| `MovieFlix-iOS-unsigned` | `Runner.app` بدون توقيع | لازم توقّعه قبل التثبيت (شوف تحت) |

> ⚠️ حزم الأندرويد **غير موقّعة** (ما كاينش keystore في المشروع) — يعني تنصبها بالـ sideload
> (تنصيب مباشر منSettings) ماشي من المتجر.

### iPhone

الـ IPA ما يتثبتش مباشرة. تحتاج واحدة من:

- **Sideloadly** أو **AltStore** بحساب Apple مجاني (التطبيق يتجدد كل 7 أيام).
- حساب **Apple Developer** مدفوع للتوقيع الدائم أو TestFlight.

## 🔐 أول تشغيل

التطبيق يطلب منك **بيانات اشتراكك أنت** (سيرفر + اسم مستخدم + كلمة سر):

1. افتح التطبيق → شاشة الدخول.
2. اكتب عنوان السيرفر (مثال: `http://example.com:8080`)، اسم المستخدم، وكلمة السر.
3. اضغط دخول — التطبيق يتأكد من البيانات ويخزّنها محلياً.

كل المحتوى (أفلام، مسلسلات، قنوات مباشرة) يجي من هذا السيرفر.

## ✨ المميزات

### التصفّح والمكتبة

- واجهة **نتفلكس**: هيرو متبدل كل 5 ثواني، صفوف أفقية، تصفّح باللمس أو الريموت.
- **6 تبويبات**: الرئيسية، أفلام، مسلسلات، مباشر، **قائمتي**، المفضلة.
- **صف Top 10** — الأكثر تشغيلاً عندك على الجهاز (عدّاد محلي).
- **صف "لأنك شفت"** — توصيات محسوبة من اللي شفته (نفس الفئة).
- **صف "وصل حديثاً"** + صفوف لكل فئة + **"قريباً"** (من TMDB).
- **"تابع المشاهدة"** مع شريط التقدم على البوستر، و**"تمت مشاهدته"**.
- **إخفاء اللي شفته** (خيار في الإعدادات).
- ترتيب المحتوى: الأحدث / الاسم / السنة / التقييم.
- **بحث فوري** في الأفلام والمسلسلات والقنوات + سجل بحث.

### المشغّل (media_kit / libmpv)

- **استكمال المشاهدة** من آخر نقطة (مع إعادة محاولة للسيرفرات اللي تتجاهل `start`).
- **تخطي المقدمة** و**تخطي النهاية** — تحدّد المدى مرة واحدة والتطبيق يحفظه.
- **لوحة "الحلقة الجاية"** بعدّ تنازلي 15 ثانية (تلقائي أو يدوي حسب الإعداد).
- **اختيار الجودة** (mp4 / mkv / ts / 4K) إن كان السيرفر يوفّر أكثر من ستريم.
- **اختيار مسار الصوت** و**الترجمة**.
- **سرعة تشغيل** 0.5x → 2x.
- **مؤقت النوم** (15/30/45/60 دقيقة).
- **أزرار 10s / 30s** ومؤشر بصري للتقديم/التأخير + سحب للصوت/الإضاءة.
- **إحصائيات التشغيل** (الدقة، البِتريت، البفر).
- **مشغّل مصغّر**: تصغّر الفيديو ويبقى شغّال تحت بقية الشاشات.
- **أبقِ الشاشة مضاءة** أثناء التشغيل (wakelock).
- **الريموت والكيبورد**: مسافة، أسهم، مفاتيح الوسائط، Enter.
- **البث المباشر** مع fallback من `m3u8` إلى `.ts`.

### التلفاز المباشر

- تصنيفات + بحث فوري + ترتيب (رقم/اسم) + فلتر "المفضلة".
- **دليل برامج (EPG)** على شكل شريط زمني، والبرنامج الجاري مُبرز.
- **إعادة (Timeshift)** للبرامج السابقة عبر رابط timeshift.
- Program info مباشر أثناء المشاهدة.

### الحساب والمستخدم

- **بروفايلات متعددة** بأفاتار، وكل بروفايل له قائمته وتقييماته وتخطياته.
- **رمز سري (PIN) على البروفايل** = رقابة parental.
- **وضع الأطفال** + **منع فئات معيّنة** (تختفي من التطبيق).
- **قائمتي (My List)** منفصلة عن المفضلة.
- **تقييم** (أعجبني / مش مهتم) يغذّي التوصيات.
- **سجل المشاهدة** + **إحصائيات المشاهدة** (الوقت الكلي، آخر 7 أيام، الأكثر مشاهدة).
- **نسخ احتياطي**: تصدير/استيراد كل البيانات (JSON) — بالـ clipboard.

### عام

- **3 لغات**: عربي / فرنسي / إنجليزي (مع RTL/LTR تلقائي).
- **وضع عدم الاتصال**: كاش على القرص + شريط تنبيه.
- **تحديث إجباري عن بعد** من ملف `server.json`.
- **Onboarding** من 3 صفحات (مرة واحدة).

  home_screen.dart     ← الرئيسية + الأقسام + البحث

### ⚠️ مجلد `android/` غير موجود في المستودع — وهذا مقصود

الـ CI يولّد مشروع الأندرويد **من الصفر** في كل build:

```bash
rm -rf android
flutter create --template app --platforms android --project-name movieflix .
```

لذلك **أي تعديل Gradle/AGP لازم يكون داخل `.github/workflows/build.yml`** أو في سكربت
يستدعيه — لو رفعت `android/app/build.gradle` راح يتمسح في كل build.

السكربت `tool/patch_android_gradle.py` مسؤول عن:

- تفعيل **core library desugaring** (شرط `flutter_local_notifications`).
- تثبيت `compileSdk 36 / minSdk 24 / targetSdk 36 / NDK 28.2.13676358` بدل `flutter.*`
  (حتى لا يكسر القالب في المستقبل).
- السكربت **idempotent** (تعمده مرتين = نفس النتيجة) ويدعم Kotlin و Groovy DSL.

### البناء محلياً

```bash
flutter pub get
flutter run                        # ملف/هاتف
flutter build apk --release        # حزمة Android
flutter build windows --release    # ويندوز
```

### التحديث عن بعد

التطبيق يقرأ `server.json` من:

```
https://raw.githubusercontent.com/mouhamedania86-creator/Update/main/server.json
```

المتوقع فيه:

```json
{
  "force_update": false,
  "latest_version": "1.1.0",
  "update_url": "https://.../MovieFlix.apk",
  "server": "http://example.com:8080",
  "username": "user",
  "password": "pass"
}
```

> 🔐 **تنبيه أمني**: حقول `server/username/password` في الملف البعيد تتحكّم في بيانات الدخول
> لكل المستخدمين. الأفضل تحطها في سيرفر خاص بيك أو تتخلص منها وتخلي كل واحد يدخل
> اشتراكه بنفسه.

## ❓ مشاكل شائعة

| المشكلة | الحل |
|---|---|
| "بيانات الدخول غير صحيحة" | تأكد من السيرفر/المستخدم/كلمة السر، وأن البانل يسمح بالـ IP تاعك. |
| "تعذر الاتصال بالسيرفر" | جرّب `http://` بدل `https://`، وتأكد من المنفذ (80/8080). |
| قسم "قريباً" فاضي | أضف مفتاح TMDB مجاني من الإعدادات (themoviedb.org). |
| الريموت ما يخدمش | التطبيق يكتشف التلفاز بـ `android.software.leanback` — لازم يكون التلفاز مفعّل عليه Leanback. |
| الفيديو يقطيع | جرّب جودة أقل من زر الجودة، أو فعّل "ترشيد البيانات". |
| نسيت رمز البروفايل | البروفايل الافتراضي (MovieFlix) ما عندوش رمز — بدّل عليه من الإعدادات. |
